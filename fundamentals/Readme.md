# **Typescript Fundamentals**

## **CMD COMMANDS:**

### To create javascript file from typescript file:

tsc 01-why-typwscript.ts

### To execute javascript code:
node 01-why-typwscript.js

## Flags:

### To avoid create js file when there is error in TS file:
--noEmitOnError

### To avoid variable or function parameters form implicitly any:
--noImplicitAny

### To avoid null values for the variable
--strictNullChecks
